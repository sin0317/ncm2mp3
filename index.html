NCM→MP3+SRT

把网易云客户端的 .ncm 文件拖进来，在本机浏览器里当场解密成可播放的 MP3 / FLAC， 歌词能一起转成 SRT 字幕。页面不发任何网络请求，断网也能用。

把 .ncm 文件拖到这里

或者 点击选择文件 · 支持一次多个 · 同名 .lrc 一起拖入会自动配字幕

想按歌曲 ID 直接下载？

那一步绕不开服务器 —— 要带你账号的会员权限去换音频地址，浏览器直连会被跨域拦掉。 所以按 ID 下载做成了联网版，会员歌填一次 Cookie 就能下。

打开联网版

本工具只处理你自己已经下载到本机的文件，音频与歌词版权归原作者及平台所有，请勿传播。

全部计算在你的浏览器里完成，页面没有任何外部资源（无 CDN、无字体、无统计），可离线保存为单个 HTML 使用。
